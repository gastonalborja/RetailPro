# RetailPro | Proyecto Final de Data Analytics

Proyecto integrador final de Data Analytics de Coderhouse.

## Objetivo del proyecto

Investigar por qué el margen de rentabilidad de la categoría **Computación y Laptops** cayó un 12 % en la **región Sur** durante el último semestre y determinar qué segmento de clientes (**Corporate** o **Retail**) explica la disminución.

## Modelo de datos propuesto

- **VENTAS**: tabla de hechos de las transacciones.
- **CLIENTES**: dimensión de clientes y segmentos.
- **PRODUCTOS**: dimensión de productos, categorías, precios y costos.
- **TERRITORIOS**: dimensión geográfica.

Las relaciones previstas son de uno a muchos (1:N) desde las dimensiones hacia VENTAS. El esquema técnico definitivo debe validarse antes de implementar las consultas.

## Herramientas

- SQL Server y T-SQL
- Power BI y Power Query
- DAX
